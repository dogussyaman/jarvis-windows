ADIM 1 — Python 3.12 Kur
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Tarayıcıdan şu adrese git:
  https://www.python.org/downloads/release/python-3128/

Sayfanın en altında "Windows installer (64-bit)" linkine tıkla.

Kurulum sırasında:
  → En alttaki "Add python.exe to PATH" kutusunu İŞARETLE
  → "Install Now" a tıkla

Kontrol etmek için terminale yaz:
  py -3.12 --version
  (Python 3.12.x çıkıyorsa tamam)

NOT: Python 3.13 veya 3.14 varsa silmene gerek yok,
     ikisi bir arada çalışabilir.

ADIM 2 — VS Code Kur
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Tarayıcıdan şu adrese git:
  https://code.visualstudio.com

"Download for Windows" butonuna tıkla, kurulumu çalıştır.

Kurulum bitince VS Code'u aç:
  → Sol taraftaki Extensions ikonuna tıkla (Ctrl+Shift+X)
  → "Python" yaz
  → Microsoft'un Python eklentisini kur


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ADIM 3 — Projeyi VS Code'da Aç
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
VS Code'da:
  File → Open Folder → jarvis-windows klasörünü seç


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
ADIM 4 — Paketleri Kur
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Proje klasöründeki setup.bat dosyasına çift tıkla. Python paketleri kurulup
React arayüzünü göstermek için gereken Microsoft Edge WebView2 kontrol edilir.

WebView2 eksikse setup.bat resmi Microsoft kurulum sayfasını açar. Runtime'ı
kurduktan sonra setup.bat dosyasını tekrar çalıştır.

Not: Hazır React arayüzü repoda derlenmiş olarak gelir. Jarvis'i kullanmak için
Node.js veya npm kurman gerekmez.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

SIK KARŞILAŞILAN HATALAR
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
"pip is not recognized"
  → pip yerine: python -m pip kullan

"No module named 'pyaudio'"
  → py -3.12 ile çalıştır, py -3.14 ile değil

PyAudio kurulumu hata verdi
  → Python 3.12 kullandığından emin ol (py -3.12 --version)
  → Sonra: py -3.12 -m pip install PyAudio

"No module named 'xxx'"
  → py -3.12 -m pip install xxx

React arayüzünü geliştirmek için Node.js 22.12 veya üstü kurulu olmalı. Proje klasöründeki
dev.bat dosyasını çalıştır. İlk kullanımda frontend paketleri yüklenir;
sonrasında React değişiklikleri açık Jarvis penceresine otomatik yansır.
Python dosyaları değiştiğinde uygulama otomatik yeniden başlar.
Geliştirme modunu kapatmak için Python terminalinde Ctrl+C'ye bas ve
React geliştirme sunucusu penceresini kapat.
